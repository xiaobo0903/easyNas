# EasyNAS

家用简易 NAS，一台低功耗 Linux 服务器 + 一块大容量硬盘，就能拥有自己的私有云。

## 解决什么问题

传统 NAS 配置复杂、功能繁多，普通家庭用户其实只需要：

- **下载功能**：PT、BT、磁力链、HTTP 下载，24 小时开着自动下载
- **文件共享**：手机、电视、电脑都能访问下载好的电影、照片
- **简单管理**：不用折腾，会用浏览器就会用

EasyNAS 就是为这个而生的。

## 核心功能

| 功能 | 说明 |
|------|------|
| 多协议下载 | 支持 BT、PT、磁力链、HTTP、FTP |
| Samba 共享 | 手机/电脑/电视直接访问文件 |
| 远程下载 | 随时添加下载任务 |
| 文件管理 | 在线浏览、删除、重命名 |

## 硬件需求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 双核 | 四核 |
| 内存 | 1GB | 2GB+ |
| 系统盘 | 10GB | 20GB+ |
| **数据盘** | 1TB | 按需配置 |

> 一台低功耗小主机（如迷你工控机）+ 一块大容量机械硬盘足矣

## 快速开始

```bash
# 克隆源码
git clone https://gitee.com/xiaobo0903/easy-nas.git
cd easy-nas

# 安装（将 /mnt/disk/downloads 替换为你的大容量硬盘挂载路径）
sudo ./deploy.sh install --downloads-dir /mnt/disk/downloads
```

安装完成后访问 `http://服务器IP`，使用 `admin / 111111` 登录。

## 文件共享

在同一局域网内，各设备访问方式：

| 设备 | 操作 |
|------|------|
| Windows | 文件资源管理器输入 `\\服务器IP` |
| macOS | Finder → 前往 → 连接服务器 → `smb://服务器IP` |
| 手机 | 文件管理器添加 SMB 服务器 |

> 首次使用需在 Web 界面「共享设置」中开启网络共享开关 |

## 管理命令

```bash
cd /opt/easy-nas

sudo ./deploy.sh status   # 查看状态
sudo ./deploy.sh logs     # 查看日志
sudo ./deploy.sh restart  # 重启
sudo ./deploy.sh stop     # 停止
```

## 适用场景

- 家庭媒体中心：下载电影、电视剧，自动共享到电视
- PT 下载党：24 小时开机，远程添加下载任务
- 照片备份：集中存储，手机电脑都能访问
- 小办公室：文件共享，无需公有云

## 为什么不选传统 NAS

| 对比 | 传统 NAS | EasyNAS |
|------|----------|---------|
| 配置 | 需要折腾 Raid、权限、网关 | 一步安装完成 |
| 功能 | 上百种功能，大部分用不到 | 只做下载和共享 |
| 性能 | 低功耗 ARM 处理器 | 直接用通用 Linux |
| 成本 | 专业设备动辄几千元 | 几百元小主机 + 硬盘 |
| 扩展 | 受限于设备 | 什么硬盘都能用 |
